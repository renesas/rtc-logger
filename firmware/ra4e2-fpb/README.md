# firmware/ra4e2-fpb

Contains the `configuration.xml` for the **FPB-RA4E2** board
(device: R7FA4E2B93CFM, Cortex-M33).

This file was generated by the Renesas RA Smart Configurator (RASC) from
the `RTC_Event_Logger_FPB_RA4E2` e2studio project and is checked in so
that `meson compile rasc_generate` can regenerate `ra_gen` / `ra_cfg`
without requiring a manual RASC re-run.

## Build

```bash
meson setup build-ra4e2 --wipe \
  --cross-file meson/llvm-cortex-m33.ini \
  -Dgen_board=ra4e2-fpb \
  -Dboard=ra4e2_fpb \
  -Dmcu=ra4e2 \
  -Dra_core=CM33 \
  -Dra_ordinal=1 \
  -Ddevice=RA4E2

meson compile -C build-ra4e2
```

See `BUILD.md` at the project root for full instructions.
