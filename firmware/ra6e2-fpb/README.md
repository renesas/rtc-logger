# firmware/ra6e2-fpb

Contains the `configuration.xml` for the **FPB-RA6E2** board
(device: R7FA6E2BB3CFM, Cortex-M33 + TrustZone, non-secure partition).

This file was generated by the Renesas RA Smart Configurator (RASC) from
the `RTC_Event_Logger_FPB_RA6E2` e2studio project and is checked in so
that `meson compile rasc_generate` can regenerate `ra_gen` / `ra_cfg`
without requiring a manual RASC re-run.

## TrustZone note

The RA6E2 has TrustZone but this project targets the **non-secure partition**
only. The `configuration.xml` here is pre-configured for the non-secure
flat-memory layout. No smart bundle (`.rpd`/`.sbd`) is required — the
`rfp_program` target uses flat SREC programming.

## Build

```bash
meson setup build-ra6e2 --wipe \
  --cross-file meson/llvm-cortex-m33.ini \
  -Dgen_board=ra6e2-fpb \
  -Dboard=ra6e2_fpb \
  -Dmcu=ra6e2 \
  -Dra_core=CM33 \
  -Dra_ordinal=1 \
  -Ddevice=RA6E2

meson compile -C build-ra6e2
```

See `BUILD.md` at the project root for full instructions.
